# HTML 网页预览方案

## 边界与数据流

- 文件列表识别 HTML/HTM，通过用户点击同步打开独立预览入口，保留目录页面状态。
- 使用带路径层级的独立文件预览路由，使浏览器按目录自然解析相对资源；路径逐段编码，避免中文、空格、问号、井号导致歧义。
- 预览路由复用登录校验、路径解析和 `os.Root` 文件句柄访问，按正确 MIME 返回 HTML 与资源；不提供目录列表或目录默认文档重定向。
- HTML 响应通过 CSP sandbox 隔离，允许普通脚本，禁止恢复同源权限；资源路由只允许读取，禁止写操作，设置 MIME 嗅探保护。
- 新窗口使用 `/html.html` 包装页提供下载入口；内部 iframe 保持 `sandbox="allow-scripts"`，在网页自行导航后继续隔离。
- opaque sandbox 不能依赖 SameSite 登录 cookie 加载资源；包装页通过认证的 `/api/html-preview` 获取独立只读 URL，`/html-files/<token>/<path>` 校验令牌对应会话仍有效。退出登录撤销令牌，令牌不能用于管理接口。
- 响应禁止缓存、引用来源传播；管理 API 拒绝 opaque Origin 与跨站请求，阻止预览页面借导航调用管理接口。

## 兼容性与取舍

- HTML 分类与源码预览契约需保持清晰；保留文件下载入口。
- 不把不受信任的 HTML 插入文件浏览器 DOM。
- sandbox 可能限制模块脚本、存储、跨域请求；本次定位为静态页面预览。

## 回滚

撤销新增预览路由及 HTML 点击分支即可恢复原有文本查看方式；无数据迁移或服务配置变更。
