# 文件列表排序功能

## 目标

增加文件排序，默认按修改时间从新到旧显示，便于优先找到刚修改的文件。

## 已确认事实

- 用户明确要求刚修改的文件排在最上面。
- 当前服务端固定目录优先、名称升序（`main.go:411`），前端直接展示响应顺序（`web/app.js:58`）。
- 接口已有名称、大小、修改时间字段，无需新增元数据。
- 当前排序提示为静态文本（`web/index.html:34`），手机端隐藏表头与该提示。

## 已确认需求

- 默认修改时间降序，最新修改的文件在文件分组最上方。
- 提供名称、大小、修改时间排序，均可切换升序和降序；桌面和手机均可操作。
- 保留目录优先，在目录和文件各自分组内排序；大小排序只比较文件大小，目录按名称排列。
- 同一页面内切换目录、返回目录和上传后刷新时保留排序选择；整页刷新恢复默认修改时间降序。
- 排序值相同按名称升序确定顺序；切换排序不清除当前文件选择或预览。

## 验收标准

- [x] 首次打开目录，文件按修改时间从新到旧排列。
- [x] 名称、大小、修改时间均支持升降序，控件准确显示当前状态。
- [x] 目录优先及相同排序值的结果稳定、可预测。
- [x] 切换目录、上传后刷新均沿用当前排序；默认状态下新上传文件排在文件分组顶部。
- [x] 桌面和手机无控件溢出；键盘可操作且有清晰标签。
- [x] 文件打开、预览、导航、上传及加载失败重试不受影响。
