# 优化深层文件查找体验

## 目标

用户记得部分文件名或项目内相对路径时，无需逐层打开目录，即可找到并预览深层文件。

## 已确认事实

- 当前页面支持目录列表、路径导航、排序及文件详情与预览（`web/index.html`、`web/app.js`）。
- 当前后端提供当前目录列表接口，尚无跨目录搜索接口（`main.go`）。
- 普通文件使用详情面板预览，Markdown、HTML/HTM 点击后打开独立预览页（`web/app.js`）。
- 文件访问使用持久化 `os.Root` 约束在配置根目录内（`main.go`、`.trellis/spec/backend/file-browser-contract.md`）。

## 需求

- R1：页面提供文件搜索输入框，按 Enter 或点击搜索按钮提交；不含 `/` 的查询按文件名部分匹配，忽略大小写。
- R2：默认搜索整个可浏览文件库，可切换为当前目录及其子目录。
- R3：支持输入 `docs/design-drafts/wukong-v14-attack-grok-handoff-v3/prompt-zh.txt` 这样的相对路径。允许省略前面的项目目录，但输入的各级目录与文件名必须连续、按完整路径段匹配文件路径末尾，不退化为只查末尾文件名。路径匹配遵循文件系统大小写。首尾空白去除；不支持绝对路径、父目录跳转或通配符。
- R4：结果展示文件名、根目录下的完整相对路径及元数据。多个项目包含同一路径时，分别列出供区分。
- R5：点击结果直接调用现有预览方式；每个结果提供“打开所在目录”入口，进入该目录并退出搜索。普通文件在详情面板预览，Markdown、HTML/HTM 沿用独立预览页。
- R6：清除查询恢复当前目录列表；搜索提供加载中、无匹配、失败及重试状态。旧请求不得覆盖新查询或目录导航后的界面。
- R7：响应式布局支持桌面和手机，长路径可换行，输入框及操作可通过键盘使用。
- R8：搜索保持登录校验和根目录访问边界。遍历达到时间、扫描数量或结果数量上限时，明确告知结果不完整；目录不可读取时显示部分搜索提示。

## 验收标准

- [x] AC1（R1、R2）：根目录或任意子目录下，搜索部分文件名可找到多层目录中的文件；切换当前目录后不返回其外的文件。
- [x] AC2（R3、R4）：`项目甲/docs/design-drafts/wukong-v14-attack-grok-handoff-v3/prompt-zh.txt` 和项目乙的相同后缀都能用示例路径找到；其他目录中的 `prompt-zh.txt` 不匹配，`mydocs/...` 也不误匹配 `docs/...`。
- [x] AC3（R4、R5）：多个同名结果可通过完整相对路径区分；点击可预览，打开所在目录后能看到对应目录列表。
- [x] AC4（R6）：快速连续搜索、切换范围、清除或目录导航后，迟到响应不改变当前界面；失败可重试，无结果与未搜索完明确区分。
- [x] AC5（R7）：桌面和手机均能输入完整示例路径并使用结果操作，长文件名和路径不撑破页面。
- [x] AC6（R8）：未登录不能调用搜索；越界路径、外部符号链接及链接循环不会越界读取或造成无限遍历；达到资源上限和部分目录不可读时显示明确状态。
- [x] AC7（R5、R6）：原有目录排序、历史导航、上传、预览及登录退出行为通过回归检查。

## 范围外

- 文件内容搜索、收藏、最近访问、目录树和页面整体重做。
- 搜索目录名称、正则表达式、通配符和拼写纠错。
- 持久化索引、后台扫描、数据库及线上部署。

## 限制与规划状态

- 首期按需扫描文件名和路径，不读取文件内容；大型目录可能触发上限，需要缩小范围。
- 不递归符号链接目录以避免循环；直接可访问的目录仍可作为当前搜索范围，通过根目录句柄校验。
- 用户已批准最终规划并明确要求开始实现；实现与验收已完成，具体检查证据见 `implement.md`。等待提交确认。
