# 实现 Go 本地文件浏览器

## Goal

提供一个可通过浏览器访问的本地项目文件浏览器，用于安全地浏览、预览、下载和上传文件，不支持修改或覆盖已有文件。

## Background

当前仓库没有业务代码，功能需要从零实现。服务部署在本机，通过 FRP 转发到 ECS2，再由 Nginx 代理到公网；应用本身必须保持本地监听和独立认证能力。

## Requirements

- 使用 Go 实现 HTTP 服务和 Web 界面。
- 根目录通过启动参数配置，默认值为用户家目录下的 `project`（`~/project`）。所有路径操作必须限制在根目录内。
- 默认监听 `127.0.0.1`，监听地址和端口可通过参数配置。
- 内置单密码登录，不提供账户体系；密码通过环境变量或启动参数配置，登录后使用安全 Cookie 会话。
- 支持目录浏览、文件下载和文件上传；不支持编辑、删除、重命名、移动或覆盖文件。
- 上传目标为当前浏览目录；同名文件必须拒绝，不覆盖、不自动改名。
- 目录只支持进入浏览，不支持整目录下载。
- 默认显示隐藏文件和目录；列表按目录优先、名称升序排列，并提供面包屑导航。
- 纯文本文件支持在线预览，读取上限为 5 MB，并展示文件大小、字符数、行数和 MIME 类型。
- 图片、视频和 PDF 支持浏览器在线预览。
- 其他文件展示文件名、路径、大小、修改时间、MIME 类型等元信息，并提供下载。
- 禁止符号链接访问根目录外的文件；所有读写操作前解析真实路径并校验根目录边界。
- 未知或不支持的文件类型不得执行，仅提供元信息和下载。

## Acceptance Criteria

- [ ] 使用默认配置启动后，仅能浏览 `~/project` 及其子目录，越界路径请求返回拒绝结果。
- [ ] 可通过参数覆盖根目录、监听地址、端口和密码来源；默认监听地址为 `127.0.0.1`。
- [ ] 未认证访问受保护页面和文件接口会被拒绝；正确密码登录后可在会话有效期内访问。
- [ ] 目录页面显示目录和文件，目录优先、名称升序，隐藏文件可见并可通过面包屑导航。
- [ ] 文件可下载；目录下载请求被拒绝或不提供下载入口。
- [ ] 上传到当前目录成功；目标存在同名文件时返回明确错误且原文件内容不变。
- [ ] 5 MB 以内的文本可在线查看并显示大小、字符数、行数、MIME；超过 5 MB 时提示下载查看且不读取完整内容。
- [ ] 图片、视频、PDF 在浏览器中可直接预览；其他类型只显示元信息并可下载。
- [ ] 符号链接指向根目录外时不可浏览、下载或作为上传目标。
- [ ] 服务不提供修改、删除、重命名、移动等写操作。

## Out of Scope

- 用户账户、角色权限、分享链接和审计系统。
- 全局搜索、复杂筛选、目录打包下载和在线编辑。
- FRP、ECS2、Nginx 的部署配置自动化；本任务只保证 Go 服务可被这些组件代理。

## Risks and Deferred Items

- 单密码适合个人或小范围使用；公网部署必须由 Nginx 提供 HTTPS，并妥善保护密码配置。
- 浏览器原生预览能力受客户端支持影响；服务只负责正确的 MIME 和流式响应。
- 大量目录项的分页和性能优化暂不纳入 MVP，必要时后续增加。
