# 实现计划

1. 初始化 Go module、目录结构和配置解析，覆盖默认根目录与监听参数。
2. 实现根目录边界检查、真实路径解析和符号链接越界防护，并补充单元测试。
3. 实现单密码登录、会话 Cookie 和认证中间件。
4. 实现目录列表、排序、面包屑数据和文件元信息 API。
5. 实现文件下载、图片/视频/PDF inline 预览及未知类型降级响应。
6. 实现 5 MiB 文本预览和字符数/行数统计。
7. 实现排他创建上传、同名冲突错误和上传大小限制。
8. 实现内嵌 Web 界面：登录、目录浏览、预览、下载、上传和错误提示。
9. 编写 API、路径安全、认证、上传冲突和预览行为测试。
10. 运行格式化、静态检查和 `go test ./...`，完成质量检查后再启动任务执行。

## 验证命令

- `gofmt -w .`
- `go test ./...`
- `go vet ./...`

## 风险文件与回滚点

- 路径安全和上传处理属于高风险边界，任何测试失败时先回滚对应 handler 变更。
- 前端与 API 契约稳定后再扩展 UI，避免同时修改协议和展示层。
