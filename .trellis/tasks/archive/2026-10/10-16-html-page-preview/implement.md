# 实施与验证计划

1. 加载前后端规范，为实施与检查代理整理规范上下文。
2. 实现经过认证、限制根目录的预览与相对资源路由，明确 MIME、只读方法和 HTML 隔离策略。
3. 增加 HTML/HTM 的新窗口打开入口及必要详情操作，保留其他类型预览行为。
4. 增加有实际行为断言的后端与前端测试，覆盖编码、相对路径、登录、越界和隔离头。
5. 执行 `go test -race ./...`、`go vet ./...`、`go build ./...`、`node --test scripts/*.test.cjs`；具备浏览器环境时验证真实渲染与相对资源。
6. 复核完整差异，按实际接口更新契约规范，记录验证结果与浏览器验证限制。

## 关注文件与回滚点

主要涉及 `main.go`、`main_test.go`、`web/app.js`，可能新增预览页与前端测试。代码变更保持可整体回退，不修改线上服务或部署配置。

## 实施前门禁

- 用户明确批准最新方案。
- 实施和检查上下文各至少包含一条真实规范记录。
- 完成规划审核后才运行 `task.py start`。
