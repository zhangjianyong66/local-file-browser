# 深层文件查找技术设计

## 边界与复用

- 继续使用 Go 单包服务和原生 HTML/CSS/JavaScript，不引入框架、数据库或构建步骤。
- 后端新增 `search.go` 及对应测试；`main.go` 仅注册路由并按需复用 `entry`、`makeEntry`、`cleanRelative`、错误和 JSON 帮助函数。
- 前端在 `web/index.html` 增加搜索表单和范围选择，在 `web/app.js` 管理搜索状态和结果，在 `web/style.css` 增加响应式样式。
- 保留当前目录作为搜索上下文；搜索结果与目录列表互斥呈现，搜索期间禁用目录排序；清除后恢复目录列表与排序。上传仍绑定当前目录，成功后退出搜索并刷新该目录。

## 数据流与接口

`输入表单 → GET /api/search?q=...&path=... → 根目录句柄内递归遍历 → JSON 结果 → 结果列表 → 现有预览或 load(父目录)`。

- `q`：必需，去除首尾空白，最长 4096 字节。无 `/` 时使用不区分大小写的文件名包含匹配。
- 含 `/` 时使用区分大小写的路径后缀匹配；实际路径等于查询，或以 `/` 加查询结尾。查询不能包含空路径段、`.`、`..`、反斜杠或起始 `/`。检查原始查询后再匹配，不能通过路径清理吞掉不合法输入。
- `path`：与列表接口相同的根目录相对目录；全库搜索传空，当前目录搜索传当前目录。必须先经现有根目录校验并确认是目录。
- 成功响应：`{path, query, entries: entry[], truncated: boolean, reason: string, skipped: number}`。`reason` 是空串、`result_limit`、`scan_limit` 或 `time_limit`；`skipped` 表示访问失败的条目/子目录数量。前端根据这些字段决定完整、无匹配或部分结果文案，不声称总匹配数量。
- 输入错误返回 400；非 GET 返回 405；范围不存在或越界沿用现有 404/403；未登录沿用 401。
- 响应中的 `path` 和每个 `entry.path` 始终是根目录相对路径，不返回本机绝对路径。

## 遍历与资源控制

- 仅通过 `server.rootFS` 打开目录和获取元数据；不使用绝对路径重新打开文件。使用标准库目录句柄和分批 `ReadDir`，避免整棵树或超大单目录一次性驻留内存。
- 仅返回常规文件，根目录内可安全解析的文件符号链接可返回；不递归符号链接目录，特殊设备/管道不进入结果。不按目录名称静默排除普通目录。
- 单次查询最多 500 个匹配、100000 个扫描条目、5 秒遍历预算；检测请求取消后停止，所有打开句柄及时关闭。预算和遍历方法应能在测试中注入较小值，覆盖上限分支而不创建海量文件。
- 扫描条目计数覆盖目录与文件；资源上限达到时立即结束，并明确返回未完成状态。时间预算限制遍历逻辑，不能保证阻塞文件系统调用的硬实时期限。
- 子目录权限错误或文件消失计入 `skipped`；起始范围打开失败仍返回请求错误。已有结果保留，前端提示部分目录未搜索。
- 对返回结果按完整相对路径稳定排序；根目录约束和目录符号链接策略防止越界与链接循环。
- 采用广度优先遍历；发现普通目录时逐段探测其下的完整查询路径，优先覆盖浅层项目。探测通过根目录句柄校验，不递归目录符号链接，计入相同扫描预算，命中结果去重。

## 前端状态与交互

- 表单提交搜索；范围使用原生选择控件；清除使用有名称和提示的图标按钮。保留现有布局密度与视觉样式。
- 独立管理查询、范围、搜索结果、加载和错误状态；请求使用 `AbortController` 加序号/版本判断，只有当前请求能渲染、更新消息或触发登录跳转。
- 新搜索、清除、目录加载、历史导航、上传刷新均使旧搜索失效；清除和导航也清理搜索选择/预览。搜索不创建新的目录历史记录。
- 切换范围时若已有查询，重新搜索；当前目录加载失败时禁用搜索，避免使用上一次成功目录作为范围。
- 复用文件打开逻辑：普通文件调用 `show`，Markdown 和 HTML/HTM 打开独立预览页。结果的所在目录按钮与文件点击独立，避免嵌套交互元素。
- 路径经 `esc` 输出，参数用 `URLSearchParams`/`encodeURIComponent` 编码。长路径换行、图标按钮提供可访问名称和 title。
- 搜索不写入 URL，刷新后回到地址栏中的目录；登录返回继续遵守现有仅携带目录的规则。

## 兼容、验证与回滚

- 不修改原有 API 的契约；新路由复用现有鉴权与跨站限制。
- Go HTTP 测试覆盖匹配、路径边界、范围、特殊字符、登录、符号链接、取消、预算及部分结果；Node 测试覆盖搜索与目录/预览的竞态。
- 使用独立临时目录和新构建二进制进行真实浏览器检查，避免读写生产数据；桌面与移动截图检查布局和预览。
- 回滚只需撤销搜索相关代码和资源并重新构建，不涉及数据迁移；本任务不重启或部署生产服务。
